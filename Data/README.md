# Local dataset files

The raw source data and intermediate audit outputs are local-only and ignored by Git. The two processed training variants are tracked so collaborators can compare them from a clone without downloading the raw images.

## Expected source layout

```text
Data/raw_data/
  Class.txt
  train/
    images/
    labels/
  valid/
    images/
    labels/
  test/
    images/
    labels/
```

Each label file is named after its image and contains one box per line:

```text
x1 y1 x2 y2 class_id
```

Coordinates are integer pixel coordinates in the source image. The current `Class.txt` order maps IDs 1 through 6 to `open`, `short`, `mousebite`, `spur`, `copper`, and `pin-hole`; use the mapping generated by Data Understanding rather than hard-coding it in training code.

## Generated folders

- `Data/derived/` is generated by Data Understanding and contains canonical pixel-coordinate targets, class mapping, and audit candidates.
- `Data/processed/none_640/` is the unchanged 640×640 reference export.
- `Data/processed/resize_512/` is the 512×512 direct-resize candidate.
- Each processed variant includes images, YOLO labels, `data.yaml`, pixel-coordinate annotations, class mapping, image manifest, normalization stats, and preprocessing config.
- Other folders under `Data/processed/` remain ignored local exports.

Run the notebooks from the repository root for the default paths. Alternatively, configure `PCB_DATA_ROOT`, `PCB_TARGETS_CSV`, `PCB_CLASS_MAPPING_CSV`, and `PCB_PROCESSED_ROOT` for local paths. Never put private credentials or access tokens in these files.
